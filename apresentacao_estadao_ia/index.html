Do chat ao agente

Chat vs. agente

  • Chat: responde perguntas em uma janela, a partir do que você pede.
  • Agente: executa uma tarefa com várias etapas — navega, roda comandos, consulta dados e edita arquivos.
  • Exemplo: em vez de perguntar como montar uma tabela, peça para pesquisar os dados, baixá-los, limpá-los e entregar o arquivo pronto.
  • Hoje, os principais agentes são o Claude Code (Anthropic) e o Codex (OpenAI/ChatGPT).
  • Ficou mais fácil usar os dois por aplicativos ou até pelo navegador: ChatGPT Work ou Claude Cowork.

IA para entrevistas

Do áudio bruto às contradições verificáveis

IA para entrevistas

Transcrever, comparar, checar

  • Os agentes conseguem transcrever praticamente qualquer áudio ou vídeo que estiver no computador.
  • Se o vídeo estiver no YouTube, dá para pedir a transcrição direto da plataforma — e analisar vários vídeos de uma vez.
  • Confronte discursos de diferentes entrevistados e documentos oficiais: entraram em contradição?
  • Peça aspas sobre um tema da entrevista ou de várias entrevistas.
  • Peça que o resultado venha em formato checável, com timecode.

IA para caçar dados públicos

Uma nova porta de entrada para a apuração

Dados públicos

O caminho até a informação

  • Falaremos mais no próximo encontro, mas a busca por dados públicos ficou muito mais fácil.
  • Como fazíamos antes? Google, dados abertos, busca online.
  • Hoje basta perguntar a um agente ou chatbot: onde tem informação sobre tal coisa?
Dados públicos · técnica

Transformar uma ideia ampla em uma pergunta investigável

  • Parta de uma ideia abstrata e peça para a IA contextualizá-la com um tema atual.
  • Ex: quero falar de datacenters no contexto eleitoral. A IA baixa os planos de governo dos candidatos e monta uma planilha de como cada um apresenta o tema — e as diferenças entre eles.
Exemplo: multas do Ibama

Comece perguntando onde estão os dados.

Depois, peça um recorte: onde houve a maior quantidade de multas?

Dados públicos

O que perguntar a uma planilha quando recebo uma?

  • Peça dicas para a IA.
  • Monte um ranking do maior pro menor.
  • Veja os outliers: quem se destaca e por quê.
  • Aponte possíveis problemas nos dados.
  • Quem produziu os dados? O que significa cada coluna?

Criatividade

Como eu fiz

  • Criei conta no GitHub ou em algum outro site de hospedar páginas, como Cloudflare Pages etc. (peça à própria IA que te ensine o passo a passo).
  • Peça ao agente para criar o jogo, com instruções específicas sobre o visual (ex: pixel art), dando referências, se possível.
  • O ideal é até gerar as imagens do jogo — bonecos, roupas — e enviar para o agente usar exatamente essa mesma imagem.
  • Explique as dinâmicas do jogo: que frases você quer usar, qual a narrativa, como se ganha ou perde pontos, etc.
  • Hospede no site (pode ser offline também).

Cuidados com a IA

Cuidados

Use como ferramenta de apuração, não como atalho

  • Muito boa para achar casos pontuais (personagens), mas nem tanto para quantificar o TODO.
  • Pode ter erros de metodologia, buscar em lugares errados ou incompletos etc.
  • Não confie 100% em análise de dados.
  • O ideal é usar em casos que você saiba o que foi feito, para checar depois.
  • Tendência de usar IA para tudo e desaprender o básico.
Cuidados

Contexto, linguagem e imagem

  • Transcrições limitadas e/ou erradas; falta de contexto.
  • Se usar com texto: evitar construções óbvias, palavras que ninguém usa.
  • Se usar com imagem: cuidado com imagens óbvias, com erros e detalhes estranhos.
  • Cheque a política da sua empresa e quais ferramentas pode/não pode usar.
Cuidados

A última etapa continua sendo humana

  • As fontes estão contempladas?
  • Se for enviar textos que vieram do chat: há algum sinal de uso de IA? (ex: 'Claro, aqui está uma versão mais enxuta do seu texto')
  • Links que o chat gera terminam com 'source=chatgpt'.
